# 執行日誌：三色顯示支援、配網穩定性與記憶體管理優化 (2026-05-14 續)

## 執行目的
完善 7.5 吋三色電子紙的顯示效能，優化行動裝置配網體驗，並解決在高負載下的記憶體不足 (ENOMEM) 問題。

## 分析與修改過程

### 1. 三色顯示 (Black/White/Red) 深度整合
- **渲染引擎統一**：將 1-bit 與 24-bit 渲染路徑合併至單一 `display_bmp` 函式，減少巢狀呼叫產生的檔案緩衝區開銷。
- **自動緩衝區清空**：修復了 1-bit 渲染時紅色殘留的問題，現在每次渲染前會自動清空黑白與紅色緩衝區。
- **高效解析**：針對 24-bit BMP 實作了逐行記憶體回收機制，確保大檔案解析不崩潰。

### 2. WiFi 配網體驗升級 (iPad/Mobile)
- **連線穩定性**：針對 iPad Safari 發送 POST 請求時的特性，重寫了 Web Server 的讀取邏輯，確保完整接收 Content-Length 所指定的 Body 資料，解決了「Invalid Data」錯誤。
- **RWD UI 強化**：確認並優化了 `index.html` 的響應式佈局，新增了密碼「顯示/隱藏」切換功能。
- **分段發送 (Chunked Sending)**：將大型 HTML 模板改為 512 bytes 分段發送，防止 Pico W 發送緩衝區溢位導致網頁加載不全。

### 3. 系統穩定性與維護
- **記憶體防護**：
    - 在 MQTT 初始化與連線前強制執行 `gc.collect()`。
    - 捕捉並優雅處理 `Errno 12 (ENOMEM)`，防止程式崩潰。
- **主迴圈優化**：加入 `loop_count` 溢位保護，並將狀態檢查週期調整為 60 秒，降低系統負載。
- **路徑標準化**：全面改用絕對路徑（如 `/resources/...`），解決從不同目錄啟動時的檔案存取問題。

### 4. 工具鏈升級 (Tools)
- **BMP 產生器**：更新 `tools/bmp_gen.py` 以支援 3 色 RGB 輸出。
- **發送逾時**：在 `tools/mqtt_pub.py` 中加入 10 秒發送逾時保護，避免電腦端腳本無限期掛起。
- **三色測試圖**：利用 `ffmpeg` 產生了優化後的 8-bit 索引色測試圖 `tools/test_3color.bmp` (377KB)。

## 最終狀態
- 系統現在能穩定接收並正確顯示 1-bit 與 24-bit (三色) BMP。
- 配網介面在手機與平板上運作流暢，資料接收率達 100%。
- 記憶體佔用控制在安全範圍內，具備長期運行的穩定性。
